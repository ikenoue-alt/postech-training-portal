# フォローアップ回答の保存設定

既存の「研修レポート」内「フォローアップ」タブへ、新しい回答を追加します。
過去19件および過去の設問列は削除・変更しません。

## 最初の設定

1. 保存先スプレッドシートを開き、「拡張機能 → Apps Script」を開きます。
2. プロジェクトに既存のコードがある場合は削除せず、新しいスクリプトファイル `Followup` を追加します。既存プロジェクトに `doGet` がある場合は、新しい独立プロジェクトで設定してください。
3. `Code.gs` の全文を貼り付けて保存します。HTMLもこの1ファイルに含まれています。
4. 関数一覧で `setup` を選び、一度実行して権限を承認します。追加する列は「回答ID」「フォーム版」です。
5. 「デプロイ → 新しいデプロイ → ウェブアプリ」で、実行ユーザーを自分、アクセスできるユーザーを「全員」にして公開します。
6. 発行された末尾 `/exec` のURLを共有してください。GitHubの報告フォームボタンをそのURLに切り替えます。

Google Workspaceの設定により「全員」を選べない場合は、管理者への確認が必要です。

## 新フォームの内容

元フォームの17項目から、元の8番「自転車の移動を減らせた」、手持ち100部、集合ポストの動作を外した14項目です。指導前・指導後の配布部数の欄もありません。
番号は01〜14です。低い評価の理由・指導内容、今回のまとめ、社員への共有を保存します。

入力内容は端末内に下書き保存され、スプレッドシートから保存完了が返ったときだけ消えます。連続クリック・通信失敗後の再送は、同じ回答IDによって二重登録を防ぎます。

「提出履歴」はスプレッドシートで管理します。公開フォームに過去の氏名・評価を表示するAPIはありません。

## 公開前の確認

公開URLで14項目・削除対象がないことを確認してから、専用の確認用回答を1件送信し、保存先を確認してください。確認用回答を削除する場合は対象行を明示してから行ってください。
本番の入口切り替えは、この確認後に行います。既存の入口はその間維持します。
